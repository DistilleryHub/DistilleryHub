# DistilleryHub V22

Included:
- Google Search Console verification meta tag
- robots.txt
- sitemap.xml
- dynamic sitemap generator template
- canonical URL
- Open Graph + Twitter metadata
- WebSite + Organization JSON-LD
- PWA manifest + service worker
- SVG favicon

Important:
1. Replace the example route URLs with the actual deployed routes.
2. Submit https://distilleryhub-b1d2d.web.app/sitemap.xml in Google Search Console.
3. For a real social network, private profiles, messages, admin pages and authenticated dashboards should NOT be indexed.
4. Public article/job/profile pages should be rendered as crawlable URLs rather than only being generated inside a client-side modal.
5. If the domain is different, replace the canonical/OG/sitemap URLs everywhere.
